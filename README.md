Project

AIDANA BEAUTY is a responsive cosmetology and beauty studio website. The
page presents beauty procedures, prices, information about the studio,
and contact details.

The main goal of the project is to demonstrate responsive web design
using CSS Media Queries and the Bootstrap 12-column Grid.

Task 0 --- Responsive Typography

For the first task, I created the introductory section of the AIDANA
BEAUTY website.

It contains:

a main heading;

a secondary heading;

paragraphs describing the project.

I used CSS Media Queries to change the font sizes for different screen
sizes:

mobile;

tablet;

laptop;

desktop.

Task 1 --- Responsive Layout with Media Queries

For this task, I created three information boxes:

Professional Care;

Quality Products;

Individual Approach.

The layout changes depending on the screen size.

On a desktop screen, the three boxes are displayed in one row. On a
tablet, the boxes are arranged into two columns, and on a mobile screen
they are stacked vertically.

This part uses CSS Media Queries without Bootstrap for the three-box
layout.

Task 2 --- Bootstrap Responsive Columns

For this task, I used the Bootstrap 12-column grid to display three
cosmetology services:

Facial Cleansing --- 7,000 ₸;

Hydrating Facial --- 8,000 ₸;

Anti-Aging Facial --- 10,000 ₸.

The Bootstrap structure uses a container, row, and responsive
col-* classes.

On large screens, the three service cards are displayed as three equal
columns. On smaller screens, the columns move to new rows and finally
stack vertically on mobile.

Work Process

I started by choosing a cosmetology and beauty studio as the topic of
the project. I planned the page around beauty procedures, prices, a
portfolio section, and contact information.

After that, I created the HTML structure and added the procedure images
and logo. I used CSS to create the milk-colored background and soft
brown information boxes.

For the responsive part, I used CSS Media Queries to change the
typography and the three-box layout for different screen sizes.

For the Bootstrap part, I used the Bootstrap 12-column grid and a
responsive Bootstrap navigation bar. Finally, I combined these parts
into one responsive portfolio page.

I checked the layout at different screen sizes and organized the project
into HTML, CSS, and image files.
